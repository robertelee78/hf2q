# Q5 early native requested-domain carrier (source-only)

This slice wires public14 native creation/live requested authorities to the
existing SAME-FD DeepSeek model/worker collector. It supplies no positive source
budget, OS proof, preload permit, physical credit, paging policy or model run.
The selected preload remains RejectedPreload with the identical fixed upper.

A private ReviewedSourceBudget has private fields in a child module and NO
constructor/Deserialize implementation. The only current producer path is the
existing unconditional reject_preload returning Err. A future independently
reviewed validator must be implemented before the typed installation path can
execute. No serialized permit boolean, global-handle lookup or caller-declared
hash can construct this carrier. PreparedLoad fields become private; its
one-shot constructor consumes that budget and the SAME parsed GgufFile/context.
Default None still invokes the original load closure.

Dry cmd_serve preflight now observes/rejects directly; it never installs or
passes a deliberately-bailing callback through the actual-load carrier. The
actual-load path repeats packet/SAME-FD/stat/header/source attachment checks.
If admitted in future, the current context must be the very same Handle before
install_early_with_live; the actual native API rejects prior/duplicate history.
No creation/history reset is performed. The model's actual GpuContext device is
registered after its constructor and before weight allocation. GpuContext's
GraphExecutor constructor only retains that device; registry registrations are
CPU source registrations. A fresh actual snapshot must still have zero root,
raw, cache, release and registered-device history before registration, so an
unexpected earlier native root denies rather than borrowing unobserved state.

Creation and live/pending ceilings are distinct and preserved. Actual snapshot
checks refuse Unknown/uncovered/legacy, denied/inflight/pending, over-cap or
arithmetic overflow. Same handle stays in the existing collector Handle carried
by the actual model and exclusively attached on the worker. Checked boundaries
revalidate its actual limits/history/device count. Errors use the existing
sticky failed/poisoned context; no second install, unobserved callback or replay.
No-handle metadata captures remain explicitly Unavailable. No-current-collector
model registration is a no-op, preserving the normal default path; active
selected loading without its actual early handle fails before weights.

Four pure controls are authored UNRUN: actual limit validator; history retained
after live release; actual Unknown/denied/pending/overflow checkpoint validator;
and actual detached/wrong collector owner refusal. One ignored fresh-process
control installs the real authority, registers an actual device, uploads64B,
transfers the SAME collector/handle to another thread, verifies actual64B
history/live and one-device snapshots, then causes duplicate-install refusal
and proves sticky failure with no later allocation/commands/replay. Its native
quota is4096B/two roots/two attempts/one device, predeclared before Device;
no GPU encoder or model/cache/file is created. It does not assert immediate
resource release or physical fit. Existing paired provider fixture/coverage
files are untouched.

Compilation and all controls are root-owned and pending. This branch retains
its seeded dependency state unchanged; no pin/publish/local patch is added.
Full source-budget/actual bounded15 metadata/geometry/provenance/OS admission
and whole-model lifecycle remain open gates.
