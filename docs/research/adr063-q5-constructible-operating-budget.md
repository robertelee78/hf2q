## Accounting and explicit assumptions

public native15 pure mapper and real cache planner, not a copied quantization or
root formula. The mandatory source minimum is SUM of complete registered root
requests + separate anonymous F32, and four full C262144 caches+C128 stub.
Window/compressed views are not extra parents. Provision requires the actual
pristine-bootstrap reuse branch; no five-cache fallback is relabeled. This
minimum is NOT a complete transient/pool-history peak or a completion promise.
The entire explicit native live+pending cap covers opaque direct, pooled, cache,
anchor and internal roots once. Bounded attempted-byte/root/raw/cache histories
are independent ceilings. There is no root/page union, low-RSS or alias credit.

Policy supplies positive CPU, tools, client, driver, observer, inactive-file
residual, retired-native residual, reaction and runtime-Free cells, plus any
additional noncase charge. They remain reviewed OPERATING allowances, not proven
allocator or unique physical partitions. CPU wire capacity is only a mandatory
floor, never a replacement for BPE/JSON/grammar/clone/channel/heap accounting or
a reason to reduce the prior3GiB CPU cell. The independent review must explicitly
name the superseded policy SHA and residual rationale before any prospective
change. The source contains NO lower real-case reserve constants.

The initial model-absent OS sample reads actual total/Free/external file pages,
normal-pressure level, swap and actual-self RSS/footprint. If explicitly enabled

is not physical ownership or retirement evidence. Its complement is already

No recommended-working-set-size/96GiB/fixed12GiB theorem is imposed: current
ADR063 dedicated-host available-RAM decision governs. All actual root requests

Optional creation-envelope mode conservatively charges the entire attempted-byte
ceiling instead of live capacity; it is NOT observed physical peak. The ordinary
operating-residual path does NOT require attempt-minus-live as a physical charge;
failed/nonallocated attempts are not retired pages. The8GiB staged experiment
kept its roots live and provides NO postDrop retirement evidence. Neither this
