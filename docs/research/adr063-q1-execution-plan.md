## Exact contract

Q1 delivers a diagnostic ORACLE that locates and records internal batching/reuse/state divergence, not a requirement to fix every backend numerical difference or every model task failure. Oracle correctness gates and backend findings are separate receipts. Q1 must diagnose divergence without universal peer text identity. Acceptance explicitly compares cold/resume, batch1/batch4, chunk size, request order and sequential/speculative; locates first norm/QKV/RoPE/attention/residual/MoE divergence with frozen intermediates; records routing margins/expert IDs/logit error/task outputs; forbids routing smoothing/tie-threshold changes/approximate recurrent replay as an exactness fix. Peer task quality uses independent fixtures with frozen margins/counts. Required validation combines intermediate/transaction comparisons, stale-state/incorrect-routing negatives and F2 task oracle.

These are TWO result domains:
- Internal invariance: identical artifact/config/token IDs and mathematically equivalent computation/state transitions. Trace values/IDs/cache metadata and first divergence, not just readable text.
- Peer task quality: same task/tool/workload/sampling/correctness oracle. Numerically different implementations may produce different valid text; exact tool names/args, compilation/tests and independent expected behavior still required.

Neither domain can stand in for the other. Q36 E0282 coding failure is a genuine task-quality FAIL, not proved numerical-state divergence; do not call it repaired because a largest-context capacity case passed.

## Full logical-extent localization and bounded storage

Order is trajectory → committed token/step → layer → source-defined graph-stage ordinal → immutable agent → logical row → element. Every stage record covers every active logical element/row, dtype, shape, cursor and relevant recurrent/cache state written by the transaction. Inactive KV capacity is recorded as capacity/ownership metadata, not copied or asserted initialized. Borrowed views retain whole-parent identity/extent in the memory packet; logical bytes do not replace parent charging.

At each checked drain, read the complete active logical extent in bounded pages (proposed 1MiB transfer page), with offset-aware row/stride handling. Stage summaries contain complete page hashes plus finite/nan/inf/sign-zero metadata. Same-route exact comparison uses every page, then byte/element localization in the first differing page. Hash equality is evidence of byte equality, not a floating tolerance bound. For floating alternate routes, compare ALL logical values with maxabs, RMS/NRMSE, cosine and decision metadata: stream paired baseline/candidate values or deterministically rerun the bounded stage window to obtain paired pages. A sampled summary cannot mark a stage numerically passed.

The first mismatching stage then gets a deterministic local rerun of preceding matching stage through the affected norm/QKV/RoPE/attention/residual/MoE window, preserving state/checkpoint provenance. Export only the first differing bounded row/page plus aggregate metrics, while retaining complete extent hashes and exact comparison coverage. Missing stage/row, reordered coordinates, incomplete extent, nondeterministic baseline or source mismatch gets explicit status, not a guessed first divergence. Claim `FirstDivergence` only when all prior required stages/extents were compared; otherwise return `LocalizationIncomplete` with the earliest observed coordinate.

Proposed comparator host buffers are two 1MiB pages plus bounded accumulator/index metadata, not full inactive KV copies. Persisted trace/page-index quota and retained OLD+NEW snapshot/whole-parent/GPU capture-root peak must be calculated per adapter before its real packet; the old blanket256MiB total was not proven and is withdrawn. A quota breach fails the diagnostic packet without truncation or changing workload. If paired-page reruns require extra model passes, disclose and bound them separately; no hidden adaptive retry-until-pass.

## Numerical policies: freeze, do not invent precision parity

Exact equality required for tokenIDs/slotidentity/cachecursor/snapshotbytes when copy-only, expertIDs in strong-margin exactdecisionfixture, trace schemas/source/caps and integerflags. For floatingvalue stages record maxabs/RMS/NRMSE/cosine/logitdifference/top1gap; compare only samequantization/mode. FP32 reduction regrouping can differ legitimately, and near-tieMoE changes must remain reported, not smoothed.

Existing ADR027 TQ-versusF32 thresholdNRMSE<=0.15 is a SPECIFIC syntheticSDPA crossrepresentation falsifier (historical measured0.008103 at its namedshape), not a universal logit/state tolerance or permission for sameTQ8 resume to differ15%. Keep TQ8 selected; no disablequantization/precisionupgrade to pass. Any perstage tolerance must cite existing exacttest/ADR/productionshape or be a NEW predeclared baselinepolicy accepted BEFORE candidate data. Unknownmodel-levelthreshold remains a concrete designdecision, not silently1e-5 or sampledafterfailure. Always retain raw errors and routingmargins even ifwithinacceptedbound.

### Executable numeric disposition table

| Domain | Oracle gate / finding |
|---|---|
| Same-route copy/state metadata, token IDs, integer flags, declared byte-invariant cache/snapshot regions | Strict exact byte/state identity; mutation and missing-page negatives must fail. No approximate recurrent replay. |
| Floating values on a path explicitly promised byte-identical | Full-extent exact comparison; actual deviation recorded as `DivergedExactInvariant`, not silently tolerated. |

| Whole TQ8/model floating policy absent | `ExplicitInconclusiveNumericPolicy`, with raw errors/extent coverage/localizer result. NEVER claim numerical PASS. This does not block writing/running a bounded diagnostic oracle. |
| Strong-margin routing fixture | IDs/order exact; valid-index swap must be caught regardless of final text. |
| General near-tie routing/logit decision | Record actual score gap, IDs/order/weights/top1 gap and changed decisions. Policy may classify sensitivity, never smooth ties, change selection thresholds, or hide an exact-axis failure. |
| Baseline T7/T8 nondeterminism | Explicit `BaselineNonDeterministic`; freeze any new baseline envelope in a separate noncandidate policy experiment before candidate acceptance. |

Oracle-positive gates prove equality, complete full-extent traversal, correct arithmetic metrics and coordinate localization using independently known fixtures. Oracle-negative gates prove stale-state refusal, one-element/page/ID corruption, extent omission, routing swap, nonfinite handling and policy-absent inconclusive status. These can PASS while an actual backend trajectory reports divergence or policy-inconclusive. Q1's diagnostic deliverable does not require fixing all findings. A complete backend-invariance PASS remains a separate claim requiring all applicable policies/gates.

Peer task oracle uses the approved F2 independent task set/counts/margins and frozen quality estimand. No arbitrary80-task prerequisite is added by Q1. Keep exact tool/argument and actual compiler/test correctness; preserve Q36 E0282 as FAIL. Q2 certifies the adversarial harness, not model task quality. A lone parse_port success is useful regression evidence, not a universal task-quality result.
