# Fastest qualified route is the default

Operator decision for hf2q, stated in the session driving the v0.1.30 release ("of course we should always have our fastest options the default"):

- Every qualified fast route is on by default. A user must never have to discover a switch to get the fast path.
- The only user-facing switches are kill switches, which turn a default route off.
- Anything a qualified model needs for its fast path (for example a DFlash2 drafter checkpoint) is fetched automatically with the model. A user must never download something separately.
- The release gate is measured on defaults, not on a configuration with opt-in switches set.

This covers qualified routes only. It is not a reason to enable a route that has not passed its qualification gates.
