# Fine-tunes of a qualified model get the fast DFlash2 path by default

Operator decision of 2026-11-12, stated in the session driving the v0.1.30 release (asked whether a fine-tune should get the fast path with no automatic drop-back: "Yes, no safety net"):

- A fine-tune of a qualified model (same architecture and shapes as a pinned DFlash2 target) gets the fast DFlash2 path by default, with the pinned drafter.
- There is no automatic drop-back to the prior route.
- `HF2Q_DFLASH2=0` is the off switch.

This supersedes the earlier rule in ADR-067 that only the exact pinned source identity qualifies ("matching dimensions did not admit the fine-tuned target"). ADR-067 on main still carried the earlier sentence when this was recorded (origin/main 5f9682ee).

State of the implementation when recorded: decided, not landed. PR #833 (open) implements it as a `SameShapes` qualification class. That PR reads "no automatic drop-back" as no acceptance-based fallback at run time and keeps one retry on the prior route when a load fails under the automatic policy; that reading is the implementer's, not part of the operator's statement. Check main before relying on any behaviour.

Evidence given with the decision (a measurement of one fine-tune, not a guarantee for others): Qwen3.8 abliterated SFT, Q4_K_M, four-agent workload, M5 Max 128 GB, a throwaway build of the PR #833 branch with the source-identity check bypassed, two runs per arm, text identical within an arm:

| Arm | Makespan s | Pass | Accepted tokens per lane-cycle |
|---|---|---|---|
| pinned drafter, full route profile | 29.56 / 27.10 | 2 of 2 | 5.318 |
| prior route | 59.42 / 59.15 | 2 of 2 | not applicable |

The vanilla pair accepted 5.254 per lane-cycle (same notes; its build is not stated there). Target bits are verified against the target model for every emitted token, so a drafter that fits a fine-tune less well costs acceptance, not correctness (PR #833 text). No external GGUF or Q5_K fine-tune had a number when this was recorded.

Related: the decision that every qualified fast route is the default and only kill switches are user-facing.
