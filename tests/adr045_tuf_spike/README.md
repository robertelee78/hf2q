# ADR-045 TUF verifier spike

This unpublished, separately locked crate tests update-authentication and
durability hypotheses for ADR-045. It is deliberately excluded from hf2q's
published crate and production dependency graph.

Nothing in this directory grants install, update, activation, or deletion
authority. Its metadata pointer and journal representations are disposable
experiment formats, not compatibility promises.

Run the full gate with Rust 1.88:

```bash
cargo +1.88.0 test --locked --lib \
  --manifest-path tests/adr045_tuf_spike/Cargo.toml \
  -- --test-threads=1
```

The retained normalization corpus under `testdata/` is generated by this
crate's `tough` 0.24 repository builder with fixed expiry values and the
public fixture-only Ed25519 seed `0x45`. The generator rebuilds snapshot and
timestamp descriptors over recursively key-sorted envelope bytes, then
pretty-serializes the timestamp without changing its signed payload. Two
independent runs must be byte-identical. This exercises exact raw-byte
retention independently of typed-role equality. These are test keys, never
release credentials.

Regenerate into an explicit scratch directory from the repository root:

```bash
HF2Q_TUF_FIXTURE_OUT=/absolute/scratch/directory \
  cargo +1.88.0 test --locked --lib \
  --manifest-path tests/adr045_tuf_spike/Cargo.toml \
  tests::regenerate_static_normalization_corpus -- \
  --ignored --exact --test-threads=1
```

Treat regeneration as a reviewed corpus change: compare the bytes, rerun both
candidate verifiers and the journal crash suite, then update the pinned
digests only when the change is intentional.
